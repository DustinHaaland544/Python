1. calendar Module

The calendar module in Python is a built-in library used to work with dates related to calendars, such as:

- Displaying calendars

- Finding weekdays

- Checking leap years

- Formatting months and years

It provides functions to generate and manipulate calendar data in a readable format.

2. Purpose

The calendar module is used to:

| Purpose               | Explanation                       |
| --------------------- | --------------------------------- |
| Display calendars     | Print month/year calendars        |
| Work with dates       | Get weekdays, days in a month     |
| Handle leap years     | Check leap year conditions        |
| Build scheduling apps | Useful in real-world applications |
| Date calculations     | Without full datetime complexity  |

3. Importing the Module

import calendar

4. Displaying Calendars

Print Full Year Calendar

import calendar

print(calendar.calendar(2026))

Output (simplified):

     January 2026
Mo Tu We Th Fr Sa Su
...

Print Specific Month

print(calendar.month(2026, 3))

     March 2026
Mo Tu We Th Fr Sa Su
                   1
 2  3  4  5  6  7  8
...

5. Important Functions

i) calendar.month(year, month)

Returns a string of the month calendar.

calendar.month(2026, 3)

ii) calendar.calendar(year)

Returns full year calendar as a string.

calendar.calendar(2026)

iii) calendar.weekday(year, month, day)

Returns the day of the week.

calendar.weekday(2026, 3, 23)

0  # Monday

iv) calendar.isleap(year)

Checks if a year is a leap year.

calendar.isleap(2024)

Output:

True

v) calendar.leapdays(start, end)

Counts leap years between two years.

calendar.leapdays(2000, 2025)

vi) calendar.monthrange(year, month)

Returns:

- First weekday of the month

- Number of days in the month

calendar.monthrange(2026, 3)

Output:

(6, 31)

Meaning:

- Month starts on Sunday (6)

- Total days = 31

6. Weekday Constants

| Day       | Value |

| Thursday  | 3     |
| Friday    | 4     |
| Saturday  | 5     |

7. Setting First Day of Week

By default, week starts on Monday.

You can change it:

calendar.setfirstweekday(calendar.SUNDAY)

8. Working with Calendar Objects

Instead of functions, you can use classes.

Example: TextCalendar

cal = calendar.TextCalendar()

print(cal.formatmonth(2026, 3))

Example: HTMLCalendar

cal = calendar.HTMLCalendar()
html = cal.formatmonth(2026, 3)

Used for web applications.

9. Iterating Through Dates

Example: Iterate Month Days

cal = calendar.Calendar()

for day in cal.itermonthdays(2026, 3):
    print(day)

Output includes:

- Actual days

- Zeros for padding

10. Real-World Example

Check if Today is Weekend

import calendar
from datetime import datetime

today = datetime.today()

day = calendar.weekday(today.year, today.month, today.day)

if day >= 5:
    print("Weekend")
else:
    print("Weekday")

11. Useful Methods Summary

| Function            | Purpose                    |
| ------------------- | -------------------------- |
| `month()`           | Get month calendar         |
| `calendar()`        | Get full year              |
| `weekday()`         | Get day of week            |
| `isleap()`          | Check leap year            |
| `monthrange()`      | Get start day + total days |
| `setfirstweekday()` | Change week start          |

12. Limitations

- Does not handle time (use datetime module)

- Output is mostly text-based

- Limited for complex date arithmetic

- Not timezone-aware

13. Common Mistakes

Confusing weekday numbers

calendar.weekday(2026, 3, 23)

Returns:

0  # Monday (not Sunday)

Forgetting import

calendar.month(2026, 3)  # Error if not imported

Expecting date objects

Calendar works with numbers, not datetime objects directly.

14. Comparison: calendar vs datetime

| Feature           | `calendar` | `datetime` |
| ----------------- | ---------- | ---------- |
| Display calendars | Yes        | No         |
| Date arithmetic   | Limited    | Powerful   |
| Time handling     | No         | Yes        |
| Formatting        | Basic      | Advanced   |

15. Key Points for Interviews

- calendar is a built-in Python module

- Used for calendar-related operations

- Weekdays are numbered from 0 (Monday) to 6 (Sunday)

- Can generate text and HTML calendars

- Works well with datetime module
